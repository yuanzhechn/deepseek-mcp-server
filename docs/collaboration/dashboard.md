# 五档切换按钮（本地控制面板）

Windows 在项目目录双击 `start-collab-dashboard.cmd`，即可在默认浏览器打开面板。首次使用先执行 `npm ci` 和 `npm run build`。也可运行：

```powershell
npm run dashboard
# 已构建或已安装的包：
node build/cli/collab.js dashboard --open
collab dashboard --open
```

面板提供 GPT 独立、质量优先、智能均衡、成本优先、自定义五个按钮；标记实际生效档位，在每个档位中分别展示 GPT 与 DeepSeek 的职责，并从面板绑定的项目目录读取项目名称，同时保留完整路径与修订号。页面不再展示顶部三张状态/费用/额度卡片。自定义按钮只启用已有规则，不生成或修改规则。

切换范围默认“当前项目”，也可选择“全局默认”。项目覆盖优先于全局默认；全局 GPT 独立是强制开关，覆盖所有项目。界面同时显示全局和项目设置，避免把“保存成功”误当作“覆盖了全局限制”。每次保存带修订号，冲突会刷新并提示重新选择；每五秒同步其他 CLI/MCP 会话所做的变化。

控制面板和 MCP 必须使用同一状态目录与项目路径。可使用 `--state-dir <目录>`、`--project <路径>`、`--port <端口>`，或已有 `DEEPSEEK_COLLAB_STATE_DIR` / `DEEPSEEK_COLLAB_PROJECT` 环境变量。默认读取操作员现有状态，不另建一套模式。新任务自动读取最新配置，正在执行的任务不变。面板不需要 DeepSeek API Key，不调用模型、不变更预算、不放宽数据或 R3 授权。

这是独立的本地页面，不是 ChatGPT 原生按钮，也不是托盘程序。关闭浏览器标签不等于关闭服务；在启动进程按 Ctrl+C 退出，MCP 不受影响。再次打开请使用启动时输出的完整链接；链接失效后重新启动生成新链接。

安全：只绑定 `127.0.0.1`，默认随机端口；每次启动使用随机访问令牌，以 URL fragment 传入并在页面加载后从地址栏移除，不放入服务器 URL 日志或页面 HTML。状态与写入 API 均要求令牌；写入同时校验 Origin、Host、JSON 类型、请求大小和版本，抵御跨站请求与 DNS rebinding。页面无第三方脚本/字体/网络请求，CSP 禁止嵌入。不要分享完整控制面板链接，它允许修改本地协作档位。此进程与原有 HTTP `/mcp` 接口隔离。

验证：`npm test` 覆盖页面、安全边界、按钮对应的持久化、跨实例可见性与修订冲突；`npm run test:package` 在干净安装中启动面板。另在隔离测试状态目录实际点击成本优先，确认页面显示“已保存”、当前档位改变且修订号递增；测试不会改变操作员的实际档位。
